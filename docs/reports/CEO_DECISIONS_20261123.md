| N4(b) / 差出人ドメイン不一致の承認メール | 承認メール（.eml）の差出人（From）のドメインが、承認する組織（顧客・セブン化学）の登録連絡先（`accounts.contact_email`）のドメインと違うときは、**自動で承認に数えない**。拒否はせず、PDF・画像と同じく**代表の手動確認**に回す。確認待ちの理由は「差出人のドメインが登録先と違います」。 | サーバーの承認算入条件に `senderVerdict !== 'mismatch'` を加える（承認記録時に `evidenceIdentifierStatus = pending_manual_verification`）。応答・確認待ち一覧・代表の承認箱に理由 `{ code: EVIDENCE_SENDER_DOMAIN_MISMATCH, message: 差出人のドメインが登録先と違います }` を載せる。~~差出人が読めない／複数（`unverifiable`）は従来どおり警告のみ~~ → **同日の修正ラウンド2で改定（下の N4(b) 改定）**。連絡先未登録（`no_registered_domain`）、メール以外（`not_email`）は従来どおり警告・中立のみ。staff の承認証跡選択の契約（代表確定のサーバー規則の一つ）は、項目も拒否条件も変えない。変わるのは算入条件だけ。2026-11-19 以前の「サーバーは警告のみ」は本決定で置き換える。 |
| N4(b) 改定（同日・修正ラウンド2、独立検収 H-1） | 差出人を読み取れない承認メール（From なし・複数・解析できない・全角＠・空のグループ・本文にだけ From・キリル文字などの読めないドメイン）は、**登録連絡先がある取引先では**自動で数えず、代表の手動確認に回す（fail-closed）。理由文は別の文言「差出人を確認できません（差出人がない・複数ある・読めない文字のドメイン）」。登録連絡先がない取引先では従来どおり警告のみ。判定は**許可リスト方式**に反転する: 正規化した From のドメインが登録ドメインと**完全一致**するときだけ自動で数え、それ以外はすべて保留（個別パターンを列挙しない）。正規化は小文字化と末尾の点の除去だけで、キリル文字・全角は正規化せず不一致扱い。サブドメインも完全一致ではないため保留。 | core `senderDomainRequiresManualVerification` は「`match` 以外は保留」。`match` は完全一致のときだけ。宣言型 `message/rfc822`・拡張子 `.eml`、またはメールのヘッダーを1つでも持つ証跡はメールとして判定する。検収の26ケースを実サーバ回帰テストに固定。 |

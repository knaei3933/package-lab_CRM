# F1 실패 시나리오·표본·백업 검증 계획 및 현황 (2026-11-15)

대표 지시 반영: **새 기능 개발 중지 — 기존 기능이 실제 업무 절차와 일치하는지 확인 우선**. NAS 배포는 전체 검증 완료 후 별도 승인.

## 1. 실패 시나리오 검증 (M8-FAIL 위임 진행 중)

| 시나리오 | 검증 방법 | 상태 |
|---|---|---|
| A. 이전 승인 재사용 (구판본 승인) | 신규 교정본 등록 후 구 승인 무효화(invalidatedByNewerRevision) + 경계 재확인 차단 | 진행 중 |
| B. 발주서 중복 발송 | 검증된 발송 이벤트 존재 시 재발송 POST → 차단 여부, 동일 주문 제2 발주서 생성 가능성 | 진행 중 |
| C. 잘못된 발송 증적 | 증빙-추적번호 미연결·미래 sentAt·증빙 누락 → SEND_UNVERIFIED 상한 확인 | 진행 중 |
| D. 발송 증명 없는 수락 | 이미 OPER3에서 차단 실측 — 테스트명으로 근거 확정 | 진행 중 |

원칙: 커버리지 있으면 기존 테스트명을 근거로 보고, 없으면 회귀 테스트만 추가. **동작이 깨져 있으면 수정하지 않고 보고** (대표 판단 대기).

## 2. §5.10 표본 검증 + evidenceIdentifier 입력 기준 (확정안 제안 — 표본 확정 대기)

**현재 구현**: 텍스트 증빙=문서 내 식별자 substring 일치 자동검증 / PDF·이미지=자동 판정 금지, `pending_manual_verification` + admin 수동검증(검증자·시각·결과·근거, 불변 이벤트).

**입력 기준 확정안 (실무 표본으로 최종 확정 필요)**:
| 승인 형태 | evidenceIdentifier 기준 (제안) |
|---|---|
| 메일 승인 | Message-ID 전체 (예: `<...@...>`) — 없으면 발신일시+발신자 주소+제목 조합 |
| 세븐 전용포탈/서면 | 문서번호 (PO-2026-xxx 등 발행번호) |
| PDF·이미지 첨부 | 식별자 입력 + admin 수동검증 필수 (자동 카운트 없음) |

**표본 2~3건 요청**: 실제 세븐화학 발주서 PDF·승인 메일 원문 — 받으면 §5.10 체크리스트로 실측 확정. (기존 대기 항목)
